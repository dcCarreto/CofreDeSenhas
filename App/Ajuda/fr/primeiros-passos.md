# Premiers pas

## 1. Créez le mot de passe maître

Au premier lancement, l'application vous demande de définir le **mot de
passe maître**. Il ouvre le coffre et ne peut pas être récupéré :
choisissez une phrase longue que vous seul connaissez et gardez-en une
copie en lieu sûr. Détails dans [Mot de passe maître](senha-mestra).

Juste après, l'application propose d'enregistrer un **QR code de secours**
du mot de passe maître. Conservez cette image hors de l'ordinateur
(imprimée ou sur un autre appareil).

## 2. Ajoutez la première entrée

Cliquez sur **Nouveau mot de passe**, renseignez le service, l'identifiant
et le mot de passe. Vous pouvez :

- générer un mot de passe fort sur-le-champ avec le
  [Générateur de mots de passe](gerador) ;
- choisir une **catégorie** et marquer l'entrée comme **favorite** ;
- ajouter des **étiquettes**, des notes et un code **TOTP** (vérification
  en deux étapes).

## 3. Au quotidien

- **Rechercher** : commencez à taper dans le champ de recherche.
- **Copier** : les boutons de chaque ligne copient l'identifiant ou le mot
  de passe. Le presse-papiers est effacé tout seul après un délai
  (réglable dans [Comportement](aparencia-acessibilidade)).
- **Verrouiller** : le coffre se verrouille tout seul après une période
  d'inactivité, ou à la demande avec *Verrouiller maintenant*.

## 4. Protégez-vous contre la perte

Configurez la [Sauvegarde et restauration](backup) et, si vous utilisez
plusieurs appareils, voyez
[Synchronisation par dossier](sincronizacao).
