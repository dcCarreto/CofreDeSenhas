# Raccourcis clavier

Les principaux raccourcis de la fenêtre du coffre :

- **Rechercher** : place le focus dans le champ de recherche.
- **Nouveau mot de passe** : ouvre le formulaire d'entrée.
- **Ouvrir le générateur** : ouvre le
  [Générateur de mots de passe](gerador).
- **Verrouiller maintenant** : verrouille le coffre immédiatement.
- **Copier l'identifiant / copier le mot de passe** de la ligne
  sélectionnée.
- **F1** : ouvre ce manuel sur la rubrique de l'écran où vous êtes.
- **Échap** : ferme la boîte de dialogue ouverte.

La liste complète, avec les touches exactes de votre version, est dans
**Paramètres → Aide → Raccourcis clavier**.
