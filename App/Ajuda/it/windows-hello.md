# Windows Hello

Ti permette di **sbloccare la cassaforte con la biometria** (impronta,
volto o PIN di Windows) invece di digitare la password principale ogni
volta.

## Come attivarlo

In **Impostazioni → Sicurezza → Attiva Windows Hello**. Windows chiede la
tua verifica e l'applicazione inizia a offrire lo sblocco con Hello nella
schermata di apertura.

## Cosa cambia e cosa no

- La **password principale resta la vera chiave** della cassaforte. Hello
  rilascia soltanto l'accesso conservato sotto la protezione del sistema.
- Le operazioni delicate (come cambiare la password principale) chiedono
  comunque la password principale.
- Se Hello non riesce o il dispositivo non lo supporta, puoi sempre
  accedere con la password principale.

## Ambito

La credenziale Hello è legata al **tuo account Windows su questo
computer**. Non viaggia con il file della cassaforte: su un altro
computer, riattivi Hello (o usi la password principale).

## Disattivare

Nella stessa schermata, *Disattiva Windows Hello*. L'accesso protetto
viene rimosso e la cassaforte torna ad aprirsi solo con la password
principale.
