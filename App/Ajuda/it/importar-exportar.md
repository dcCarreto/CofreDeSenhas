# Importare ed esportare

## Importare da un altro gestore

In **Impostazioni → Backup e sincronizzazione → Importa da CSV**. La
maggior parte dei gestori esporta un file **CSV**; l'applicazione
riconosce i formati più comuni e ti fa controllare la corrispondenza delle
colonne prima di terminare.

> Il CSV esportato da altri programmi è in **chiaro**, non cifrato. Dopo
> l'importazione, elimina quel file in modo sicuro.

## Esportare la cassaforte

L'esportazione produce un file **cifrato**, protetto da una password che
imposti al momento. Usala per migrare su un altro computer o per tenere
una copia a lungo termine fuori dal formato di [Backup](backup).

Per reimportare, apri l'applicazione sul computer di destinazione e usa
l'opzione di importazione sul file esportato, inserendo la password usata
per l'esportazione.

## Passare a un altro computer

1. Esporta la cassaforte (o copia un [Backup](backup)).
2. Installa l'applicazione sull'altro computer.
3. Importa il file e inserisci la password.
4. Se vuoi tenerli entrambi sincronizzati, configura la
   [Sincronizzazione cartella](sincronizacao).
