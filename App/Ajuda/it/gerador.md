# Generatore di password

Il generatore crea password casuali forti. Aprilo dal pulsante a forma di
chiave nella barra laterale, o direttamente nel modulo di una voce.

## Opzioni

- **Lunghezza**: più è lunga, più è forte. Per la maggior parte dei
  servizi, 16 caratteri o più.
- **Tipi di carattere**: maiuscole, minuscole, cifre e simboli.
  Disattiva i simboli solo quando il servizio non li accetta.
- L'indicatore di forza mostra in tempo reale quanto è resistente la
  password.

## Usare la password generata

- Nella schermata **Nuova password** o **Modifica**, il generatore
  compila direttamente il campo della password.
- Nella schermata **Nuova password**, facendo clic sul campo della
  password vuoto compare una **password sicura suggerita**: fai clic su di
  essa (o premi Invio) per usarla, oppure sul pulsante accanto per
  suggerirne un'altra. Esc chiude il suggerimento.
- Altrove, il generatore ha un pulsante di copia. Gli appunti vengono
  svuotati automaticamente dopo qualche secondo.

## Buona pratica

- Una **password diversa per ogni servizio**. Così una violazione su un
  sito non compromette gli altri.
- Non cercare di memorizzare le password generate — è per questo che
  esiste la cassaforte.
- Il [Rapporto di sicurezza](seguranca) segnala le password deboli o
  riutilizzate che conviene cambiare.
