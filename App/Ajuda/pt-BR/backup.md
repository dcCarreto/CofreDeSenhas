# Backup e restauração

Um backup é uma cópia cifrada do cofre inteiro, aberta pela mesma senha
mestra. Serve para se recuperar de uma falha de disco, um apagão acidental
ou a troca de computador.

## Backup automático

Em **Configurações → Backup e sincronização → Backup e restauração** você
define:

- a **frequência** (por exemplo, semanal);
- o **número máximo de backups** guardados — os mais antigos são
  descartados quando o limite é atingido.

Os backups automáticos ficam na pasta de dados do aplicativo. Como estão
no mesmo computador, eles **não substituem** uma cópia externa.

## Backup manual

Na mesma tela, gere um backup na hora e salve onde quiser — de preferência
num pendrive ou serviço de arquivos que você controle.

## Restaurar

Escolha um arquivo de backup e confirme. O conteúdo atual é **substituído**
pelo do backup. Se o cofre estiver conectado a um banco de dados, a
restauração se comporta de forma diferente — leia o aviso na tela.

## Exportar

Para migrar ou guardar fora do formato de backup, veja
[Importar e exportar](importar-exportar).
