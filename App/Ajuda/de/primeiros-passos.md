# Erste Schritte

## 1. Master-Passwort erstellen

Beim ersten Start bittet Sie die Anwendung, das **Master-Passwort**
festzulegen. Es öffnet den Tresor und kann nicht wiederhergestellt werden:
Wählen Sie einen langen Satz, den nur Sie kennen, und bewahren Sie eine
Kopie an einem sicheren Ort auf. Einzelheiten unter
[Master-Passwort](senha-mestra).

Gleich danach bietet die Anwendung an, einen **Sicherungs-QR-Code** des
Master-Passworts zu speichern. Bewahren Sie dieses Bild außerhalb des
Computers auf (ausgedruckt oder auf einem anderen Gerät).

## 2. Ersten Eintrag hinzufügen

Klicken Sie auf **Neues Passwort**, füllen Sie Dienst, Benutzername und
Passwort aus. Sie können:

- mit dem [Passwortgenerator](gerador) sofort ein starkes Passwort
  erzeugen;
- eine **Kategorie** wählen und den Eintrag als **Favorit** markieren;
- **Schlagwörter**, Notizen und einen **TOTP**-Code
  (Zwei-Schritt-Verifizierung) hinzufügen.

## 3. Im Alltag

- **Suchen**: Fangen Sie an, im Suchfeld zu tippen.
- **Kopieren**: Die Schaltflächen jeder Zeile kopieren den Benutzernamen
  oder das Passwort. Die Zwischenablage wird nach einer Weile von selbst
  geleert (einstellbar unter [Verhalten](aparencia-acessibilidade)).
- **Sperren**: Der Tresor sperrt sich nach Inaktivität von selbst oder auf
  Wunsch über *Jetzt sperren*.

## 4. Gegen Verlust absichern

Richten Sie [Sicherung und Wiederherstellung](backup) ein und sehen Sie,
wenn Sie mehrere Geräte nutzen,
[Ordner-Synchronisierung](sincronizacao).
