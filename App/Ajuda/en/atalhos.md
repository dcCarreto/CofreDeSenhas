# Keyboard shortcuts

The main shortcuts of the vault window:

- **Search**: focuses the search box.
- **New password**: opens the entry form.
- **Open the generator**: opens the [Password generator](gerador).
- **Lock now**: locks the vault immediately.
- **Copy username / copy password** of the selected row.
- **F1**: opens this manual at the topic for the screen you're on.
- **Esc**: closes the open dialog.

The full list, with the exact keys for your version, is in
**Settings → Help → Keyboard shortcuts**.
