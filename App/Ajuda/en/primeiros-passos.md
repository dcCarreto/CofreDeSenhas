# Getting started

## 1. Create the master password

On first launch, the app asks you to set the **master password**. It opens
the vault and cannot be recovered — choose a long phrase that only you
know and keep a copy somewhere safe. Details in
[Master password](senha-mestra).

Right after, the app offers to save a **backup QR code** of the master
password. Keep that image away from the computer (printed or on another
device).

## 2. Add the first entry

Click **New password**, fill in service, username and password. You can:

- generate a strong password on the spot with the
  [Password generator](gerador);
- pick a **category** and mark it as a **favorite**;
- add **tags**, notes and a **TOTP** code (two-step verification).

## 3. Use it day to day

- **Search**: start typing in the search box.
- **Copy**: the buttons on each row copy the username or password. The
  clipboard is cleared automatically after a while (adjustable in
  [Behavior](aparencia-acessibilidade)).
- **Lock**: the vault locks itself after inactivity, or on demand with
  *Lock now*.

## 4. Protect yourself against loss

Set up [Backup and restore](backup) and, if you use more than one device,
see [Folder sync](sincronizacao).
